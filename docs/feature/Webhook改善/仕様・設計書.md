## 🎨 画面仕様

### 1. トップページ（/）- Webhook履歴セクション追加

#### 画面概要
トップページの最下部に、Webhook受信履歴を表示するセクションを追加。最新5件の履歴をテーブル形式で表示し、10秒ごとに自動更新される。

#### 表示項目

| 項目 | 表示形式 | 説明 |
|------|----------|------|
| イベント | バッジ（色分け） | 作成:緑、更新:黄、削除:赤 |
| タスクID | 数値 | タスクの一意識別子 |
| タスク名 | テキスト | タスクのタイトル |
| 優先度 | バッジ | high/medium/low |
| 期日 | 日付 | YYYY-MM-DD形式（未設定時は"N/A"） |
| 受信時刻 | 相対時刻 | 「〇〇秒前」「〇〇分前」「〇〇時間前」 |

#### イベント種別の色分け仕様

| イベント | ラベル | CSSクラス | 色 |
|----------|--------|-----------|-----|
| created | ✨ 作成 | badge-success | 緑 |
| updated | ✏️ 更新 | badge-warning | 黄 |
| destroyed | 🗑️ 削除 | badge-danger | 赤 |

#### 表示ロジック

1. **初期状態**: 空メッセージを表示、テーブルは非表示（`style="display: none;"`）
2. **履歴あり**: 空メッセージを非表示、テーブルを表示
3. **履歴なし**: 空メッセージを表示、テーブルを非表示
4. **最大表示件数**: 5件（`data.webhook_logs.slice(0, 5)`）
5. **更新頻度**: 10秒ごとに自動更新（`setInterval(fetchWebhookLogs, 10000)`）

## 📜 JavaScript仕様

### ポーリング機能

#### 概要
10秒ごとに`/api/webhook_logs`を呼び出し、Webhook履歴を取得してテーブルを更新する。

#### 実装場所

**ファイルパス**: `views/index.erb` (223〜302行目)

#### 主要関数

##### 1. fetchWebhookLogs()

Webhook履歴を取得してテーブルを更新するメイン関数。

**処理フロー**:
1. fetch API で `/api/webhook_logs` を呼び出し
2. レスポンスをJSON形式でパース
3. 履歴の有無で表示を切り替え
4. 履歴があれば、最新5件をテーブルに挿入
5. エラー時はコンソールにログ出力

**実装**:
```javascript
function fetchWebhookLogs() {
  fetch('/api/webhook_logs')
    .then(response => response.json())
    .then(data => {
      const logsContainer = document.getElementById('webhook-logs-tbody');
      const emptyMessage = document.getElementById('webhook-empty-message');
      const logsTable = document.getElementById('webhook-logs-table');

      if (data.webhook_logs && data.webhook_logs.length > 0) {
        // Webhook履歴がある場合
        emptyMessage.style.display = 'none';
        logsTable.style.display = 'table';

        // テーブルをクリア
        logsContainer.innerHTML = '';

        // Webhook履歴を表示（最新5件）
        data.webhook_logs.slice(0, 5).forEach(log => {
          const row = document.createElement('tr');

          // イベント種別の色分け
          let eventBadgeClass = '';
          let eventLabel = '';
          if (log.event === 'created') {
            eventBadgeClass = 'badge-success';
            eventLabel = '✨ 作成';
          } else if (log.event === 'updated') {
            eventBadgeClass = 'badge-warning';
            eventLabel = '✏️ 更新';
          } else if (log.event === 'destroyed') {
            eventBadgeClass = 'badge-danger';
            eventLabel = '🗑️ 削除';
          }

          row.innerHTML = `
            <td><span class="badge ${eventBadgeClass}">${eventLabel}</span></td>
            <td>${log.task.id}</td>
            <td>${log.task.title}</td>
            <td><span class="badge badge-${log.task.priority}">${log.task.priority || 'N/A'}</span></td>
            <td>${log.task.due_date || 'N/A'}</td>
            <td>${formatTimestamp(log.timestamp)}</td>
          `;

          logsContainer.appendChild(row);
        });
      } else {
        // Webhook履歴がない場合
        emptyMessage.style.display = 'block';
        logsTable.style.display = 'none';
      }
    })
    .catch(error => {
      console.error('Webhook履歴の取得に失敗しました:', error);
    });
}
```

##### 2. formatTimestamp(timestamp)

タイムスタンプを「〇〇秒前」「〇〇分前」「〇〇時間前」形式に変換する関数。

**処理ロジック**:
- 60秒未満: 「〇〇秒前」
- 60分未満: 「〇〇分前」
- 24時間未満: 「〇〇時間前」
- 24時間以上: 元のタイムスタンプをそのまま表示

**実装**:
```javascript
function formatTimestamp(timestamp) {
  const now = new Date();
  const past = new Date(timestamp);
  const diffMs = now - past;
  const diffSec = Math.floor(diffMs / 1000);
  const diffMin = Math.floor(diffSec / 60);
  const diffHour = Math.floor(diffMin / 60);

  if (diffSec < 60) {
    return `${diffSec}秒前`;
  } else if (diffMin < 60) {
    return `${diffMin}分前`;
  } else if (diffHour < 24) {
    return `${diffHour}時間前`;
  } else {
    return timestamp;
  }
}
```

## 🗂️ データ仕様

### セッションデータ構造

Webhook履歴はセッション（`session[:webhook_logs]`）に保存される。

**データ型**: Array（配列）

**最大件数**: 10件（古い履歴は自動削除）

**データ構造**:
```ruby
session[:webhook_logs] = [
  {
    event: 'created',         # イベント種別（String）
    task: {                   # タスク情報（Hash）
      'id' => 1,              # タスクID（Integer）
      'title' => 'テスト',     # タスク名（String）
      'priority' => 'high',   # 優先度（String）
      'due_date' => '2025-12-21', # 期日（String）
      'completed_at' => nil,  # 完了日時（String | nil）
      'created_at' => '2025-12-14T12:00:00Z', # 作成日時（String）
      'updated_at' => '2025-12-14T12:00:00Z'  # 更新日時（String）
    },
    timestamp: '2025-12-14T12:00:00Z' # Webhook受信時刻（String）
  }
]
```

### 保存ロジック

**実装場所**: `app.rb` (144〜151行目)

```ruby
# セッションにWebhook履歴を保存（最新10件まで）
session[:webhook_logs] ||= []
session[:webhook_logs].unshift({
  event: payload['event'],
  task: payload['task'],
  timestamp: payload['timestamp']
})
session[:webhook_logs] = session[:webhook_logs].first(10)
```

**保存方式**:
1. 新しい履歴を配列の先頭に追加（`unshift`）
2. 配列を最新10件にトリミング（`first(10)`）
3. 古い履歴は自動的に削除される
