# 仕様・設計書 - due_date任意化（task_api_tool）

## 📋 基本情報

- **機能名**: タスク作成フォームでdue_date（期日）任意化
- **関連Issue**: #6
- **作成日**: 2025-12-22

---

## 🎯 機能概要

タスク作成フォームのdue_date入力欄を必須から任意に変更します。これにより、ユーザーは期日を設定せずにタスクを作成できるようになります。

---

## 📐 設計詳細

### UI設計

#### タスク作成フォーム変更

**ファイル**: `views/index.erb`

**変更箇所**: 87〜90行目

**変更前**:
```html
<div class="form-group">
  <label for="due_date">期日 <span class="required">*</span></label>
  <input type="date" id="due_date" name="due_date" required>
</div>
```

**変更後**:
```html
<div class="form-group">
  <label for="due_date">期日 <span class="optional">（任意）</span></label>
  <input type="date" id="due_date" name="due_date" placeholder="期日を選択（任意）">
</div>
```

#### 変更内容の詳細

**1. ラベルの変更**

**Before**: `期日 <span class="required">*</span>`
**After**: `期日 <span class="optional">（任意）</span>`

- **意図**: ユーザーに期日が任意であることを明示
- **スタイル**: `.optional`クラス（グレー表示など、`.required`と対照的なスタイル）

**2. required属性の削除**

**Before**: `<input type="date" id="due_date" name="due_date" required>`
**After**: `<input type="date" id="due_date" name="due_date" placeholder="期日を選択（任意）">`

- **意図**: ブラウザの必須入力チェックを無効化
- **効果**: 空欄でもフォーム送信が可能になる

**3. placeholder属性の追加**

**Before**: なし
**After**: `placeholder="期日を選択（任意）"`

- **意図**: ユーザーに期日が任意であることを再度案内
- **効果**: フォーム入力時のユーザビリティ向上

### CSS設計（今後の改善案）

#### `.optional`クラスの定義

**ファイル**: `public/css/style.css`（今後追加予定）

```css

  color: #888;
```

- **色**: グレー（#888）で目立ちすぎないようにする

## 🔍 API連携設計

### 既存のAPI呼び出し

**ファイル**: `app.rb:49〜78`

**エンドポイント**: `POST /tasks/create`

**リクエストパラメータ**: `params[:due_date]`

**動作**:
1. フォームから`due_date`パラメータを取得
2. 空文字列の場合は何も送信しない（現状実装なし）
3. 値がある場合はAPIに送信

**変更内容**:

**現状**:
```ruby
params_hash = {
  task: {
    title: params[:title],
    due_date: params[:due_date],  # 空文字列でも送信
    priority: params[:priority]
  }
}
```

**問題点**:
- `due_date`が空文字列（""）の場合、APIに送信されてしまう
- task_learning_app APIは空文字列をnilに変換できない可能性がある

**改善案（今後検討）**:
```ruby
params_hash = {
  task: {
    title: params[:title],
    due_date: params[:due_date],
    priority: params[:priority]
  }
}

# due_dateが空文字列の場合は削除
params_hash[:task].delete(:due_date) if params[:due_date].to_s.empty?
```

**優先度**: Could Have（現状、task_learning_app側で空文字列を適切に処理できる場合は不要）

## 🎨 UI改善（今後の検討）

### 現状の課題

- `.optional`クラスのCSSが未定義（赤文字で表示される可能性）
- 期日なしタスクの表示スタイルが不明確

### 改善案

#### 1. `.optional`クラスのCSS追加

**ファイル**: `public/css/style.css`

```css
.optional {
  color: #888;
  font-size: 0.9em;
  font-weight: normal;
  font-style: italic;
}
```

#### 2. 期日なしタスクの表示改善

**現状**:
```erb
<td><%= task['due_date'] || 'N/A' %></td>
```

**改善案**:
```erb
<td>
  <% if task['due_date'] %>
    <%= task['due_date'] %>
  <% else %>
    <span class="no-date">期日なし</span>
  <% end %>
</td>
```

**CSS**:
```css
.no-date {
  color: #aaa;
  font-style: italic;
}
```
