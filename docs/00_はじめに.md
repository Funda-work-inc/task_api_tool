# 00_はじめに

## このツールについて

**Task API Tool** は、Rails API（task_learning_app）をブラウザから視覚的にテストするためのWebベースのツールです。

## 何ができるのか

このツールを使うと、以下の操作をブラウザ上で簡単に実行できます：

- ✅ **タスク一覧の表示**：task_learning_appに登録されているタスクを一覧表示
- ✅ **タスクの作成**：新しいタスクをフォームから作成
- ✅ **タスクの更新**：既存のタスクの情報を更新
- ✅ **タスクの削除**：不要なタスクを削除

## なぜこのツールを作ったのか

通常、REST APIをテストするには以下のような方法があります：

1. **curlコマンド**：ターミナルから複雑なコマンドを入力する必要がある
2. **Postman**：高機能だが、初心者には設定が難しい
3. **RailsコンソールやRSpecテスト**：開発者向けで、非エンジニアには使いづらい

**Task API Tool**は、これらの課題を解決し、**誰でも簡単にブラウザから**APIをテストできるようにするために作られました。

## 想定読者

このドキュメントは、以下のような方を対象としています：

- **プログラミング初心者**：APIやHTTPの基礎を学びたい方
- **Web開発を学びたい方**：REST APIの仕組みを実際に動かしながら理解したい方
- **task_learning_appの開発者**：APIが正しく動作しているか確認したい方

## このツールで学べること

Task API Toolを使うことで、以下のような知識を実践的に学ぶことができます：

### 1. HTTPメソッドとCRUD操作の対応関係
- GET → Read（読み取り）
- POST → Create（作成）
- PATCH → Update（更新）
- DELETE → Delete（削除）

### 2. REST APIの基本構造
- エンドポイント（URL）の設計
- リクエストとレスポンスの流れ
- JSONデータフォーマット

### 3. クライアント・サーバーモデル
- ブラウザ（クライアント）
- task_api_tool（中間サーバー）
- task_learning_app API（バックエンドサーバー）
- データベース

### 4. エラーハンドリング
- HTTPステータスコード（200, 404, 422, 500など）
- バリデーションエラーの処理
- ネットワークエラーの対処
