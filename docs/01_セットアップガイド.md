# 01_セットアップガイド

## 前提条件

Task API Toolを使用するには、以下の環境が必要です：

### 必須環境
- ✅ **Ruby 3.x** がインストールされていること
- ✅ **task_learning_app** が正常に動作していること
- ✅ task_learning_appが **http://localhost:3000** で起動していること

### 確認方法

#### Rubyのバージョン確認
```bash
$ ruby -v
# 出力例: ruby 3.3.0 (2023-12-25 revision ...) [arm64-darwin23]
```

Ruby 3.x以上が表示されればOKです。

#### task_learning_appの起動確認
別のターミナルウィンドウで以下を実行します：

```bash
$ cd /Users/fukumotokichiyou/task_learning_app
$ bin/rails server
```

ブラウザで `http://localhost:3000` にアクセスして、task_learning_appが表示されることを確認してください。

---

## インストール手順

### Step 1: プロジェクトディレクトリに移動

```bash
$ cd /Users/fukumotokichiyou/task_api_tool
```

### Step 2: 依存ライブラリのインストール

```bash
$ bundle install
```

**何が起こっているか？**
- `Gemfile`に記載されているRubyのライブラリ（gem）をインストールします
- 主なライブラリ：
  - **sinatra**：軽量なWebアプリケーションフレームワーク
  - **sinatra-contrib**：Sinatraの拡張機能（開発時の自動リロードなど）

**成功時の出力例：**
```
Fetching gem metadata from https://rubygems.org/...
...
Bundle complete! 2 Gemfile dependencies, X gems now installed.
```

## 正常に起動しているか確認する

### ✅ 確認ポイント1: ページが表示される

ブラウザで `http://localhost:4567` にアクセスすると、以下のようなページが表示されます：

- ヘッダー：「🔧 Task API Tool」
- サブタイトル：「task_learning_app の REST API をテストするためのツール」
- タスク一覧表示エリア

### ✅ 確認ポイント2: task_learning_appとの通信が成功している

- タスク一覧が表示される（タスクが登録されている場合）
- または「📝 タスクがありません」のメッセージが表示される

**もしエラーメッセージが表示される場合は、[04_トラブルシューティング.md](04_トラブルシューティング.md) を参照してください。**

## 起動中の2つのサーバー

Task API Toolを使用する際は、**2つのサーバーが同時に起動**している必要があります：

| サーバー | ポート | URL | 役割 |
|---------|--------|-----|------|
| task_learning_app | 3000 | http://localhost:3000 | Rails API（データベースと通信） |
| task_api_tool | 4567 | http://localhost:4567 | WebUI（APIクライアント） |

### なぜ2つ必要なのか？

```
[ブラウザ] → [task_api_tool (4567)] → [task_learning_app API (3000)] → [データベース]
```

- **task_api_tool**：ブラウザからの操作を受け取り、APIリクエストを送信
- **task_learning_app**：APIリクエストを処理し、データベースを操作

## 停止方法

### task_api_toolの停止

task_api_toolを起動したターミナルで `Ctrl + C` を押します。

```bash
^C== Sinatra has ended his set (crowd applauds)
```

### task_learning_appの停止

task_learning_appを起動したターミナルで `Ctrl + C` を押します。

```bash
^C- Gracefully stopping, waiting for requests to finish
=== puma shutdown: ...
- Goodbye!
```
