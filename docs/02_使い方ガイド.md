# 02_使い方ガイド

このガイドでは、Task API Toolの各機能の使い方を、実際の操作手順とともに説明します。

---

## 画面の構成

Task API Toolのメイン画面は、以下のセクションで構成されています：

### 1. ページヘッダー
- タイトル：「📋 タスク一覧」
- 説明文

### 2. タスク一覧テーブル
- 登録されているタスクが表示されます
- 表示項目：ID、タイトル、期日、優先度、完了状態、作成日時

### 3. タブパネル
- **📝 タスク作成**：新しいタスクを作成
- **✏️ タスク更新**：既存のタスクを更新
- **🗑️ タスク削除**：タスクを削除

### 4. 再読み込みボタン
- タスク一覧を最新の状態に更新

---

## 機能1: タスク一覧の表示

### 概要
task_learning_appに登録されているタスクを一覧表示します。

### 操作手順

1. ブラウザで `http://localhost:4567` にアクセス
2. 自動的にタスク一覧が表示されます

### 表示される情報

| カラム | 説明 | 表示例 |
|--------|------|--------|
| ID | タスクの一意な識別番号 | 1, 2, 3... |
| タイトル | タスクの内容 | 買い物に行く |
| 期日 | タスクの期限 | 2025-12-15 |
| 優先度 | タスクの重要度 | LOW / MEDIUM / HIGH |
| 完了 | 完了状態 | ✅ 完了 / ⏳ 未完了 |
| 作成日時 | タスクが作成された日時 | 2025-12-13T12:00:00Z |

### 優先度の色分け

- **LOW（低）**：青色のバッジ
- **MEDIUM（中）**：黄色のバッジ
- **HIGH（高）**：赤色のバッジ

### タスクがない場合

「📝 タスクがありません」というメッセージが表示されます。

---

## 機能2: タスクの作成

### 概要
新しいタスクをフォームから作成します。

### 操作手順

#### Step 1: タスク作成タブを開く
- 画面下部のタブから「📝 タスク作成」をクリック

#### Step 2: フォームに入力

| 項目 | 必須 | 説明 | 入力例 |
|------|------|------|--------|
| タイトル | ✅ 必須 | タスクの内容 | 買い物に行く |
| 期日 | ✅ 必須 | タスクの期限 | 2025-12-15 |
| 優先度 | 任意 | タスクの重要度（デフォルト: 中） | 低 / 中 / 高 |
| プロジェクトID | 任意 | 関連するプロジェクトのID | 1 |

#### Step 3: 「✨ タスクを作成」ボタンをクリック

#### Step 4: 結果を確認

**成功時：**
- 画面上部に緑色の成功メッセージが表示されます
  ```
  ✅ タスクを作成しました！（ID: 123）
  ```
- タスク一覧に新しいタスクが追加されます

**エラー時：**
- 画面上部に赤色のエラーメッセージが表示されます
  ```
  ❌ タイトルを入力してください
  ```

### よくあるエラー

| エラーメッセージ | 原因 | 対処法 |
|-----------------|------|--------|
| タイトルを入力してください | タイトルが空欄 | タイトルを入力する |
| 期日を入力してください | 期日が空欄 | 期日を選択する |
| APIサーバーに接続できません | task_learning_appが起動していない | task_learning_appを起動する |

## 機能3: タスクの更新

### 概要
既存のタスクの情報を更新します。

### 操作手順

#### Step 1: タスク更新タブを開く
- 画面下部のタブから「✏️ タスク更新」をクリック

#### Step 2: 更新するタスクを選択

**タスクが存在する場合：**
- ドロップダウンメニューから更新したいタスクを選択
  ```
  ID: 1 - 買い物に行く
  ```

**タスクが存在しない場合：**
- タスクIDを手動で入力

#### Step 3: 更新したい項目を入力

| 項目 | 説明 | 注意点 |
|------|------|--------|
| タイトル | 新しいタイトル | 空欄の場合は変更されません |
| 期日 | 新しい期日 | 空欄の場合は変更されません |
| 優先度 | 新しい優先度 | 「変更しない」を選択した場合は変更されません |

#### Step 4: 「🔄 タスクを更新」ボタンをクリック

#### Step 5: 結果を確認

**成功時：**
```
✅ タスクを更新しました！（ID: 1）
```

**エラー時：**
```
❌ タスクが見つかりません
```

### 更新のポイント

- **部分更新が可能**：変更したい項目だけを入力すればOK
- **空欄は変更されない**：入力しなかった項目は元のまま維持されます

### 例：期日だけを変更したい場合

1. 更新するタスクIDを選択：`ID: 1 - 買い物に行く`
2. 期日だけを入力：`2025-12-20`
3. タイトルと優先度は空欄のまま
4. 更新ボタンをクリック

→ 期日だけが更新され、タイトルと優先度は変更されません

## 機能4: タスクの削除

### 概要
不要なタスクを削除します。

### ⚠️ 重要な注意事項
**削除したタスクは元に戻せません！** 削除する前に、本当に削除してよいか確認してください。

### 操作手順

#### Step 1: タスク削除タブを開く
- 画面下部のタブから「🗑️ タスク削除」をクリック

#### Step 2: 削除するタスクを選択

**タスクが存在する場合：**
- ドロップダウンメニューから削除したいタスクを選択
  ```
  ID: 1 - 買い物に行く
  ```

**タスクが存在しない場合：**
- タスクIDを手動で入力

#### Step 3: 警告メッセージを確認

フォーム内に警告メッセージが表示されます：
```
⚠️ 削除したタスクは元に戻せません。本当に削除してもよろしいですか？
```

#### Step 4: 「🗑️ タスクを削除」ボタンをクリック

#### Step 5: 確認ダイアログで「OK」をクリック

ブラウザの確認ダイアログが表示されます：
```
本当にこのタスクを削除してもよろしいですか？
```

- **削除する場合**：「OK」をクリック
- **キャンセルする場合**：「キャンセル」をクリック

#### Step 6: 結果を確認

**成功時：**
```
✅ タスクを削除しました（ID: 1）
```

**エラー時：**
```
❌ タスクが見つかりません
```

## タスク一覧の再読み込み

### 操作方法

画面下部の「🔄 再読み込み」ボタンをクリックします。

### いつ使うか

- タスクを作成・更新・削除した後
- 最新のタスク一覧を確認したい時
- task_learning_app側で直接タスクを変更した後

---

## フラッシュメッセージについて

### 成功メッセージ（緑色）

```
✅ タスクを作成しました！（ID: 123）
```

操作が成功した時に表示されます。

### エラーメッセージ（赤色）

```
❌ タイトルを入力してください
```

操作が失敗した時に表示されます。

### 表示場所

画面上部のメインコンテンツエリアの直下に表示されます。

### 自動的に消える？

- **消えません**：別のページに移動するまで表示され続けます
- 再読み込みやタブ切り替えをすると、新しいメッセージに置き換わります

---

## よくある操作パターン

### パターン1: 新しいタスクを追加して確認

1. 「📝 タスク作成」タブを開く
2. フォームに入力して「タスクを作成」
3. 成功メッセージを確認
4. タスク一覧に新しいタスクが表示されることを確認

### パターン2: タスクの期日を変更

1. 「✏️ タスク更新」タブを開く
2. 更新したいタスクをドロップダウンから選択
3. 新しい期日を入力（他の項目は空欄のまま）
4. 「タスクを更新」をクリック
5. タスク一覧で期日が更新されたことを確認

### パターン3: 完了したタスクを削除

1. タスク一覧で削除したいタスクのIDを確認
2. 「🗑️ タスク削除」タブを開く
3. 削除したいタスクをドロップダウンから選択
4. 「タスクを削除」をクリック
5. 確認ダイアログで「OK」
6. タスク一覧から消えたことを確認
